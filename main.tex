%
%  - Chaque partie du document est un fichier séparé, importé plus bas avec
%    \include{...} : pagetitre, introduction, chap_presentation, chap_<service> ...,
%    conclusion. Ces fichiers ne contiennent ni préambule ni \begin{document}. Un chapitre
%    commence par \section{...} (la classe est article : un chapitre = une \section) ;
%    l'introduction et la conclusion sont des \section* ajoutées au sommaire.
%  - Un chapitre = un fichier chap_<nom>.tex. L'ordre des chapitres (et donc leur numéro)
%    est celui des \include plus bas : pour réordonner, déplacer une ligne.
%  - Le cours est découpé en cinq parties (\part), qui reprennent le fil de lecture :
%    I Fondations, II Le socle IaaS, III Exploiter le cloud, IV Services de plateforme,
%    V Mettre en œuvre. Chaque \part est écrite en tête du premier chapitre de la partie
%    (chap_presentation, chap_nova, chap_horizon, chap_ironic, chap_deploiement), juste avant
%    son \section : si l'on déplace ce chapitre, déplacer aussi la \part.
%  - Nouveau document : modifier le bloc « Informations du document »,
%    ajouter ou retirer des \include, décommenter les sections utiles
%    (résumés, table des illustrations, annexes).
%  - Compilation : pdflatex main, biber main, pdflatex main, pdflatex main.
%    (deux passes de pdflatex au minimum : sommaire, renvois, page de titre TikZ)
%  - Couleurs de la charte : insarouge (principale) et insagris (secondaire),
%    relevées sur le logo INSA. À utiliser dans les chapitres (figures, tableaux).
%  - Glossaire : entrées dans glossaire.tex, appel \gls{iaas} dans le texte.
%    Bibliographie : références dans sources.bib, appel \parencite{cle}.

% Messages d'un diagramme de séquence : \seqmsg{x de départ}{x d'arrivée}{y}{numéro (ou vide)}{étiquette}
% (flèche pleine) et \seqrep (flèche pointillée = réponse). La pastille numérotée se place du côté de
% l'émetteur, hors de la flèche, pour ne pas recouvrir l'étiquette posée au-dessus.
\newcommand{\seqmsg}[5]{%
  \draw[msg] (#1,#3) -- (#2,#3) node[midway, above=1pt, font=\footnotesize, align=center, text=black, fill=white, inner sep=1pt] {#5};%
  \ifx\relax#4\relax\else\node[num] at ({#1+(#2>#1?-0.4:0.4)},#3) {#4};\fi}
\newcommand{\seqrep}[5]{%
  \draw[rep] (#1,#3) -- (#2,#3) node[midway, above=1pt, font=\footnotesize, align=center, text=black, fill=white, inner sep=1pt] {#5};%
  \ifx\relax#4\relax\else\node[num] at ({#1+(#2>#1?-0.4:0.4)},#3) {#4};\fi}
